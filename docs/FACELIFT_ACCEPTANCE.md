# Troy Facelift Acceptance

The facelift is ready for final acceptance when all of the following pass:

1. Access, Home, Projects, Describe, References, Footage, Final Details, Cooking, Rough Cut, and Settings visually match Troy's approved compositions.
2. No Troy Studio, mock projects, Clerk authentication, simulated renderer, alternate backend, or OpenReel code is present.
3. A real project analyzes supplied media, produces a structured validated timeline, and renders a playable MP4 with FFmpeg.
4. The Rough Cut screen plays that MP4 and exposes Approve and Request Changes.
5. Request Changes produces a new version without repeating eligible paid analysis.
6. Approval records only the latest successful render as positive project evidence.
7. The full PBJ automated suite passes and the app launches with Python/FFmpeg only.
8. Portrait and landscape physical-iPhone testing passes for safe areas, uploads, progress, playback, revisions, approval, download, interruption, and Home Screen PWA behavior.

Phase 7 remains awaiting physical-iPhone acceptance. The owner may either approve and merge the branch or request changes after that run.
